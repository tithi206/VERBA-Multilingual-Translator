# 🌐 VERBA 2.0 – Multilingual Translator

**Connecting Languages, Connecting People**

VERBA 2.0 is an AI-powered multilingual translation prototype that helps users translate text between multiple languages.

## 🚀 Features
- Supports 22 language options
- Multilingual text translation
- Language swapping
- Interactive Gradio interface
- Translation performance benchmarking

## 🧠 Model
This project uses Meta AI's pretrained **NLLB-200 Distilled 600M** model from Hugging Face.

Model: `facebook/nllb-200-distilled-600M`

## 🛠️ Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- SentencePiece
- Gradio

## ⚙️ Installation

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd VERBA-Multilingual-Translator

pip install -r requirements.txt
```

## ▶️ Run the Project

Open `VERBA2_0.ipynb` in Google Colab or Jupyter Notebook and execute the cells in order.

The pretrained model will be downloaded from Hugging Face.
